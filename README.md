# DWT Encryption Project

> 👉 **Everything you need is in [FINAL/](FINAL/).**

Open the FINAL folder. That's where the presentation files, speaker scripts, and study materials live. Start with [FINAL/00 - START HERE.md](FINAL/00%20-%20START%20HERE.md).

Everything else in this folder is backstage:

- **`_reference/`** — long-form academic backup (project report, concept files, paper verbatim, Python reference code).
- **`_meta/`** — admin (prof brief, requirements breakdown, class message draft).
- **`_build/`** — Python script that generates the PPTX/PDF/PNG outputs. Run `python _build/build_deck.py` to rebuild.

You do not need to open any of those to give the presentation.
